# Microsoft Agent Framework in .NET

This repository contains the code samples for:

> **Microsoft Agent Framework in .NET: Build production-grade AI agents and multi-agent systems in C#**

formerly known as **Microsoft Semantic Kernel in Action** and **Building AI Agents in .NET** published with Manning.

The book is now available independently on Leanpub:

👉 https://leanpub.com/agentframework

## Book status

The Leanpub edition currently includes **11 of 16 chapters**. The remaining five chapters—and all future updates—will be delivered to Leanpub readers at no additional cost.

This project began as *Microsoft Semantic Kernel in Action*, later became *Building AI Agents in .NET*, and now continues independently as *Microsoft Agent Framework in .NET*, updated for the GA release of Microsoft Agent Framework.

All code changes, new examples, and notes for upcoming chapters are published in this repository. To follow the project, please star the repository and follow me on LinkedIn:
